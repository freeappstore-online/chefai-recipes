# Chefai Recipes

AI-powered recipe assistant that respects your dietary restrictions and guides you step-by-step through cooking with live tweaks.

**Live:** https://chefai-recipes.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `chefai-recipes`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
